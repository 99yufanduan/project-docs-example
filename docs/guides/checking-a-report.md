# 检查自己的报告

1. 找到上游报告的重投影 RMSE 和平均极线误差，统一为像素。
2. 按[报告接口](../reference/report-interface.md)填写 `metrics` 与 `limits`。阈值使用该次验收约定。
3. 运行 `python3 check_report.py report.json`。若总体未通过，在 `checks` 中找到 `passed: false` 的项目，对照数值与阈值。
4. 将检查输出与原报告一起归档，便于追溯判断依据。

> **注意**　比较前应核对原报告的统计口径。平均极线误差和最大极线误差应分别使用对应阈值。

## 输入报错

- **无法打开文件**。核对当前目录、报告路径和读取权限。
- **某字段必须是非负有限数值**。检查字段名和数值类型。JSON 中应写 `0.5`，带引号的 `"0.5"` 是字符串。
- **JSON 解析失败**。核对文件语法和 UTF-8 编码。
