# 验证记录

基于 Python 3.10.12 从仓库根目录运行 CLI。两份样例为合成报告，验证目标是判断规则和命令行契约。

| 需求 | 输入或场景 | 核对结果 |
|---|---|---|
| R1、R3 | `examples/passing.json` | 平均极线误差等于上限，两项及总体通过，退出码 `0` |
| R1、R3 | `examples/failing.json` | 重投影项通过，平均极线误差超限，总体未通过，退出码 `1` |
| R2 | 文件不存在、JSON 语法错误、根节点为数组、缺少 `limits` | 退出码 `2`，错误写到标准错误，标准输出为空 |
| R2 | 必需字段为布尔、字符串、负数或无穷大 | 退出码 `2`，错误包含对应字段 |
| 技术需求 | 比较两份样例执行前后的文件内容 | 输入文件内容一致 |

复跑两条正常路径见[示例](../examples/report-checks.md)。检查错误分支时可以对样例副本移除 `limits` 后运行。

本轮验证覆盖报告读取、数值比较和输出。实机采集、求解精度和独立验收需要使用实际数据，见[项目状态](../../STATUS.md)。
