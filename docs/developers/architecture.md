# 系统设计

代码位于 [check_report.py](../../check_report.py)。一个入口串起文件读取、字段校验、阈值判断和命令行输出，小规模示例可以沿着同一文件阅读。

```text
报告 JSON → 基本结构与数值校验 → 逐项比较 → 总体结论 → JSON 输出与退出码
```

`check_report()` 负责读取和判断，`main()` 负责解析参数并把异常转换成命令行错误。读入的报告保留在原路径。通过和超限共用输出结构，调用方可以读取具体失败项。数据错误在判断前返回，避免与超限混淆。

接口约束见[技术需求](requirements.md)。复测输入和预期结果见[验证记录](../validation/smoke-checks.md)。
