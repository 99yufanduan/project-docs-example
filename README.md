# 项目文档结构示例

本仓库用一个双目标定报告检查工具演示如何组织项目文档。工具读取报告里的重投影误差和平均极线误差，逐项比较阈值，并返回可供脚本读取的检查结果。

需要 Python 3.10 或更新版本。从仓库根目录运行：

```bash
python3 check_report.py examples/passing.json
```
